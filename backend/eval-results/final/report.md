## What was measured, and what could not be

The evaluation ran against a real PostgreSQL instance with every real migration applied and the corpus seeded through the real chunker. Retrieval therefore exercised the actual SQL function and indexes.

**Answer-level metrics were not measured.** Answer correctness, faithfulness, claim-level attribution and unsupported-answer rate all require a generation model. No model provider is reachable from the environment that produced this report, so those rows are absent by necessity, not by choice. They are not estimated.

## Metric definitions

| Metric | Definition |
|---|---|
| Recall@K | Fraction of ground-truth relevant documents present in the top K passages,counting a document once however many passages it contributes. Undefined for cases with no relevant documents, which are excluded from the mean. |
| Precision@K | Fraction of the top K passages whose document is relevant. Defined as 0for cases with no relevant documents, so flooding context on an unanswerable question is penalised. |
| MRR | Reciprocal rank of the first relevant passage; 0 if none. Undefined forunanswerable cases. |
| nDCG@K | Binary-gain discounted cumulative gain, normalised by the ideal ordering. |
| Citation precision | Of the documents retrieved (the citations an answer would carry),the fraction that are relevant. |
| Citation recall | Of the relevant documents, the fraction retrieved. |
| Abstention correct | 1 when the system returned evidence exactly when evidence exists,else 0. |
| False abstention | Among answerable cases, the fraction where nothing was returned. |


## Limitations of this evaluation

1. **Lexical-only.** Without embeddings, semantic retrieval was never exercised. Recall figures here are a floor for a hybrid deployment, not an estimate of it.
2. **No answer-level scoring.** Retrieval metrics say nothing about whether a generated answer would be faithful.
3. **Small corpus, authored questions.** 22 cases over 7 documents is enough to expose categorical failures and not enough to estimate a stable population parameter. Differences of a few hundredths are noise.
4. **Substring ground truth.** Where correctness would need judgement, it is not scored rather than scored by a model acting as its own judge.
5. **No human review.** No case was adjudicated by a person; the expectations were authored with the corpus and are shown in `dataset.json` for inspection.
